# LINIA — сайт языковой школы

**Самостоятельный демонстрационный проект:** адаптивный сайт языковой студии с каталогом программ, расписанием групп и интерактивной формой интереса к обучению.

**[Открыть демосайт](https://anya-karpova.github.io/language-school-demo/)** · [Исходный код](https://github.com/anya-karpova/language-school-demo)

> Проект создан для портфолио. Это не сайт действующего клиента: названия курсов, стоимость, количество мест и другие сведения демонстрационные.

## Задача

Сделать удобный интерфейс, в котором посетитель может быстро разобраться в предложениях языковой школы, подобрать подходящую группу по параметрам и оставить заявку на уровне демонстрационного пользовательского сценария.

## Что реализовано

- Адаптивный одностраничный интерфейс для компьютеров и смартфонов.
- Разделы программ и расписания, навигация по странице и мобильное меню.
- Карточки учебных групп с уровнем, форматом, расписанием, стоимостью и количеством мест.
- Фильтрация групп по параметрам, сброс фильтров и состояние пустой выдачи.
- Загрузка демоданных о группах через REST API на Cloudflare Worker; на стороне API используется Cloudflare D1.
- Отдельные состояния загрузки и ошибки получения данных.
- Модальное окно с формой и клиентской валидацией введённых значений.

## Сценарий пользователя

1. Посетитель переходит на сайт и знакомится с направлениями обучения.
2. Открывает расписание и задаёт нужные фильтры.
3. Выбирает группу и открывает форму.
4. Проверяет интерактивный сценарий оформления интереса к группе.

## Технологии

- **Frontend:** HTML5, CSS3, JavaScript.
- **API:** получение списка групп по HTTP из Cloudflare Worker / D1.
- **Публикация frontend:** GitHub Pages.

Фронтенд находится в этом репозитории. Код удалённого API не включён сюда.

## Ограничения демоверсии

- Форма **не отправляет настоящую заявку**, не создаёт бронь и не сохраняет персональные данные на сервере. Отправка перехватывается JavaScript и используется для демонстрации взаимодействия и валидации.
- Изменения в расписании зависят от доступности отдельного API. При отсутствии связи интерфейс показывает состояние ошибки.
- Платежей, подтверждений записи и готовой CRM-интеграции здесь нет.

Перед запуском для реального бизнеса потребуются серверная обработка заявок, проверка персональных данных, юридические документы, тестирование интеграций и работа с реальным содержимым школы.

## Как посмотреть локально

Скачайте репозиторий и запустите в каталоге с `index.html` простой веб-сервер:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для загрузки групп потребуется соединение с внешним API.

## Что демонстрирует проект

Работу с адаптивной вёрсткой, визуальной иерархией, клиентскими сценариями, фильтрами, формами и REST API. Это **учебный/портфолийный кейс**, а не отчёт о коммерческих результатах.
